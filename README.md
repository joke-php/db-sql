# Joke DB SQL

---

**В разработке**

---

Библиотека для работы с реляционными базами данных в рамках фреймворка Joke. Поддерживает PDO-драйверы MySQL,
PostgreSQL, SQLite, и т.п. Включает управление подключениями, транзакции с savepoints и конфигурацию через
типизированные объекты.

## В планах

- [ ] абстрактный класс логера реализующий основной функционал, но оставляющий на ответственность разработчика
  подготовку запроса и данных перед записью в лог
