# Руководство по миграции на Joke DB v2

В версии 2.0 обновлен интерфейс `Vasoft\Joke\Db\Sql\Contract\ConnectionInterface`. Если вы реализовывали собственные драйверы или декораторы подключения, вам необходимо внести одно изменение.

## 1. Добавление метода `getLastInsertId`

Ваш класс, реализующий `ConnectionInterface`, теперь обязан содержать новый метод для получения идентификатора последней вставленной записи.

**Добавьте следующую сигнатуру в вашу реализацию:**

```php
public function getLastInsertId(?string $sequenceName = null): string;
```

## 2. Требования к реализации

*   **Тип возврата:** Метод должен возвращать `string`. Это позволяет корректно работать с большими числами (BigInt) или специфичными типами ID.
*   **Обработка ошибок:** Ваша реализация должна проверять результат вызова драйвера. Если идентификатор не может быть определен, необходимо выбросить исключение `Vasoft\Joke\Db\Sql\Exceptions\QueryException`. 
*   **Поддержка последовательностей:** Аргумент `$sequenceName` является опциональным, но ваша реализация должна уметь передавать его в драйвер БД (это критично для корректной работы с PostgreSQL).
