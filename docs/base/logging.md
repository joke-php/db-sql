# Логирование запросов

Иногда полезным может быть логирование запросов, для этого `\Vasoft\Joke\Db\Sql\ConnectionManager` имеет метод
`loggable(SqlLoggerInterface $logger, string $connectionName = '', LogMode $logMode = LogMode::All): ConnectionInterface`
который возвращает запрашиваемое подключение обернутое в декоратор (реализует интерфейс
`\Vasoft\Joke\Db\Sql\Contract\ConnectionInterface`), который выполняет логирование.

Параметры метода следующие:

- `logger` - обязательный, логер реализующий `\Vasoft\Joke\Db\Sql\Contract\SqlLoggerInterface`
- `connectionName` - не обязательный, имя подключения. Если пустая строка или не передано - подключение по умолчанию.
- `logMode` - режим логирования.

Возможные режимы:

| Режим                    | Назначение                                               |
|--------------------------|----------------------------------------------------------|
| `LogMode::ExecutionOnly` | Логировать только выполнение запроса на стороне сервера. |
| `LogMode::FetchOnly`     | Логировать только чтение результатов.                    |
| `LogMode::All`           | Логировать все этапы: и выполнение, и чтение.            |

Модуль не включает в себя готовую реализацию логера. Связано это с тем, что в запросах могут быть данные, которые не
должны попадать в системы логирования (например, персональные данные). Поэтому реализация логера зависит от специфики
проекта. О том как создать свой логер можно узнать в статье [Создание логера](../dev/logger.md)

Декоратор реализован в `Vasoft\Joke\Db\Sql\Logger\LoggableConnection`. Оборачивает реальное соединение и перехватывает
вызовы методов query/execute/transaction. При этом передает объекту логера время выполнения операции, SQL-запрос, параметры запроса, количество затронутых строк и текст ошибки (если она возникла).
